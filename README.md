# CUT BLEND — Luxury Cinema Studio & Photography Portfolio

CUT BLEND is a portfolio website built for a video editing studio and photography team specializing in luxury destination weddings, supercar delivery & track commercials, 5-star hospitality brand films, viral fashion reels, and macro product cinema.

## ✨ Features

- **8-Second Full-Screen Video Preloader:** Full-viewport immersive preloader with center zoom crop and automatic smooth transition to the main showcase.
- **24K Gold & Onyx Black Aesthetic:** Theme featuring glassmorphism, gold glow accents, and typography (`Syne`, `Plus Jakarta Sans`, `JetBrains Mono`).
- **Side-by-Side Cinema Showcase:** Side-by-side video monitors with interactive playback controls, video mode switchers, and project narratives.
- **Live Instagram Integration:** Dynamic `@cutblend.studios` profile card with real-time stats and an interactive 6-item Reels grid.
- **Interactive Color Lab Before/After Slider:** DaVinci-style color grading comparison slider with interactive LUT presets.
- **Micro-Animations & Audio Engine:** GSAP ScrollTrigger animations, smooth scrolling via Lenis, custom gold cursor follower, and synthesized Web Audio sound effects.
- **Fully Responsive:** Optimized for both mobile devices (portrait viewports with `100dvh`) and 4K desktop screens.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser, or run a local static server:

```bash
# Using Python
python -m http.server 5173

# Using Node.js (npx)
npx serve .
```

Then visit `http://localhost:5173` in your browser.
